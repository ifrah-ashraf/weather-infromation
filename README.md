## WeatherNow - My First Deployed Weather Website!

Welcome to **WeatherNow**, a simple and clean weather forecast web app that displays real-time weather information such as:

- 🌡️ **Temperature**
- 💨 **Wind Speed**
- 💧 **Humidity**

## [Website ](https://weather-information-nine.vercel.app/)  


### Features

-  Real-time weather data
- City-wise search
- Clean and minimal design



### Technologies Used

- **HTML/CSS/JavaScript**
- **OpenWeatherMap API** (for live weather data)
